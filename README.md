# Internet Rural — Angular MVP

Landing page MVP desarrollada con Angular, TypeScript, HTML y CSS.

## Estructura

- Navbar
- Hero / Inicio
- Sobre nosotros
- Cobertura
- Planes por zona
- Testimonios
- Contacto
- Footer

## Ejecutar

```bash
npm install
npm start
```

Luego abrir:

http://localhost:4200

## Importante

Los datos de contacto, testimonios y algunos textos son demostrativos.
Antes de publicar la página se deben reemplazar por la información oficial
de la empresa.

El correo y los enlaces de Telegram son placeholders y deben configurarse.
